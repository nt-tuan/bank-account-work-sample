Layout rules

  • Topbar 56 px charcoal (menu icon + wordmark). Sidebar 240 px charcoal; groups in muted text; selected item = white row, charcoal text.
  • Each page starts with a white pagebar (64 px): list pages show the title on the left; drill-down and flow pages show “‹ Back” left + centered title. Transfer flow pages add a 3 px blue underline.
  • Content: canvas #F4F5F7, padding 24/32, max 1200 px. Blocks are flat white, radius 4, no border; sections separated by 20 px gaps. Section titles sit outside the block, above it.
  • Navigation entries are full-width white rows with a chevron (see below).
  • Spacing 4-px scale: 8 / 12 / 16 / 20 / 24 / 32. Touch targets ≥ 44 px.
  • < 810 px: mobile shell (charcoal header, white bottom nav). Usable at 320 px.

Buttons and action bar

  • Buttons never sit inside text content. They live in one action bar at the end of the page, outside the white block: right-aligned in flows (Back is in the pagebar, Next/Confirm bottom-right), centered on result/detail pages.
  • Inline actions next to content (Change, Copy, Retry, Refresh, Check again, Clear filters) are text links with an optional 16 px icon, so they align with surrounding text.
  • Min width 160 px, centered label. Primary blue, outline blue, orange only for Confirm transfer.
